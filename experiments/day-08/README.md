# Day 08 — границы дообучения на Средиземье

**Обучение и финальная оценка завершены.** Выбран checkpoint-704 по dev до открытия final. На новых формулировках обученных фактов: база **0/86**, улучшенный промпт **1/86**, адаптер **13/86**, база с правильной справкой (oracle) **25/86**. Это консервативная AI-разметка полных ответов, без независимой человеческой проверки.

JSON-схема: **2/17 → 17/17**, но точный контент у адаптера только **4/17**. Стиль: **3/6 → 5/6**, очень малая выборка. Общие задачи: **32/40 → 23/40**; десять регрессий, из них девять связаны с форматом и одна — со смыслом. Адаптер не стал надёжным справочником. Oracle не является готовой RAG-системой.

## Проверка без модели

Из корня репозитория:

```sh
python3 -m unittest discover -s experiments/day-08 -p 'test_*.py'
python3 -m unittest discover -s experiments/day-08/training-v1 -p 'test_*.py'
python3 experiments/day-08/verify_dataset.py
```

Последняя команда проверяет структуру, контрольные суммы и побайтовую пересборку корпуса во временной папке. Без `--tokenizer` MLX не нужен. Сохранённая validation_report.json описывает историческую проверку токенизатора, не повторный GPU-прогон публикации.

## Повторный запуск и целостность

Веса, адаптеры, checkpoint-файлы и логи не включены. Для обучения нужны Apple Silicon/Metal, MLX-окружение и отдельно подготовленная модель; путь задаётся `MODEL_PATH`. Код использует исправленный loss из опубликованного day-06. Используйте отдельную рабочую копию: исторические скрипты могут создавать или перезаписывать результаты. Чат с checkpoint-704 требует отсутствующие в репозитории веса адаптера.

Исходные данные и data/manifest.json сохранены побайтово. release_manifest.json отражает локальное состояние до обучения; его флаги и хеши документации исторические. README обновлены, пути в коде настроены через окружение, личные пути в метаданных заменены маркерами. Актуальные хеши публичной копии — [в отдельном манифесте](../../publication-day-08-09-manifest.json).
