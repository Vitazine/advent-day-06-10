## Проверки без модели

Из корня репозитория, Python 3.12+:

```sh
python3 -m unittest discover -s experiments/day-09 -p 'test_*.py'
python3 experiments/day-09/evaluate.py --references experiments/day-09/data/final-accepted.jsonl --predictions experiments/day-09/evaluation/before-final/responses.jsonl --output /tmp/day09-before.json
python3 experiments/day-09/evaluate.py --references experiments/day-09/data/final-accepted.jsonl --predictions experiments/day-09/evaluation/after-final/responses.jsonl --output /tmp/day09-after.json
```

Для итоговой оценки используется final-accepted.jsonl (79 примеров после аудита), а не исходные 80 в final-reference.jsonl. Отклонённый случай и причина сохранены в audit-holdout.json.

Выходные файлы должны отсутствовать: оценщик не перезаписывает существующие результаты. Код оценки использует опубликованные contract.py и score_candidates.py из day-07. Модель не загружается.

## Повторное обучение и архив

Веса, адаптеры, ZIP для сдачи, дубли submission, логи, PID и оперативные статусы исключены. Для повторного обучения нужны MLX/Metal, модель через `MODEL_PATH` и исходный адаптер day-07 iteration-4; он тоже не опубликован. Используйте отдельную рабочую копию. Исторические pipeline/finish-скрипты требуют полного локального архива и не служат универсальной командой воспроизведения из публичной копии.

manifest.json и манифесты коротких промптов проверяют неизменённые данные. code-manifest.json и исторические evidence хранят хеши исходного локального кода/весов; они не являются проверкой отредактированной публичной копии. Личные пути заменены маркерами, модель настраивается окружением. Актуальные хеши — [в манифесте публикации](../../publication-day-08-09-manifest.json).
