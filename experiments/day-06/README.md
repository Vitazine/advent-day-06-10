## Публичный состав

Код, синтетические dev/final/general, исходные генерации, разметка, метрики и параметры четырёх основных прогонов. Веса, адаптеры и корпусные train/valid ru_paradetox не включены. Источник корпуса и revision указаны в отчёте; data/manifest.json хранит исторические контрольные суммы, включая исключённые файлы. integrity.json — результат прежней локальной проверки с весами, не новой проверки публичной копии.

Из корня репозитория, Python 3.12+:

```sh
python3 -m unittest discover -s experiments/day-06 -p 'test_*.py'
```

Код обучения опубликован для изучения протокола. `common.py` читает каталог прежних исходных ресурсов из `DAY6_SOURCE_DIR` (по умолчанию source-day-06). Подготовка требует исходные TSV, model-4b-provenance.json, dataset-report.json, qwen4b-official-template.jinja и модель в models/Qwen3-4B-Instruct-2507-4bit этого каталога. Они не входят в публикацию. `verify.py` требует полный локальный архив, включая веса и данные всех прогонов; он не предназначен для урезанного публичного пакета. `build_report.py` также является архивным генератором отчёта и может требовать исключённые артефакты.

Для нового обучения нужны Apple Silicon/Metal и окружение из provenance; используйте отдельную рабочую копию и запускайте run.py напрямую нужным Python. Готовый чат без модели и адаптера из этой публикации не запускается.
